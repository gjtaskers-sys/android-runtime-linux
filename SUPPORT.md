# Support

This project is an experimental source preview; there is no stable release or
formal support commitment yet.

- **Bug reports:** use GitHub Issues and include exact commands, versions, and
  sanitized logs.
- **Feature or architecture discussion:** open a GitHub Discussion if enabled,
  or use an issue clearly marked as a proposal.
- **Build and testing instructions:** start with `README.md`, then see
  `docs/BUILDING.md`, `docs/DEV_ANDROID.md`, and `docs/ARCHITECTURE.md`.
- **Security concerns:** follow `SECURITY.md`; do not disclose exploit details
  publicly.

Questions about building AOSP should state the exact build target, source
manifest revision, host hardware, and failure log. Ordinary contributors do
not need to build AOSP to work on the host runtime.
