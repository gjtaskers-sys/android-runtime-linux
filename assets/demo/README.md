# Demonstrations

These short, cropped clips show independently tested prototype components:

- `2048-android-sdk-emulator.mp4`: 2048 running in the Android SDK development emulator. It does not demonstrate the custom LXC runtime.
- `x11-synthetic-gradient.mp4`: generated RGB frames shown by the host-side native X11 display helper. It is not Android-rendered output.
- The `*-preview.gif` files are optimized README previews of those recordings.

The clips are intentionally cropped to the relevant application windows. The raw desktop recordings are not included.
